# Job Applications & Careers Portal

A sleek, responsive careers and applicant tracking web portal featuring real-time candidate verification, dynamic role filtering, and automated application submission workflows.

## 🚀 Live Demo
**Hosted Website:** [https://aryanpalla198.github.io/Job-portal-/](https://aryanpalla198.github.io/Job-portal-/)

---

## ✨ Features
- **Modern Career Listings:** Filter and explore open roles across Engineering, DevOps, QA, and Customer Success.
- **Application Submission:** Streamlined candidate form with resume upload and cover letter support.
- **Client & Cloud Integration:** Ready for Google Apps Script webhook integration or custom backend API.
- **Mobile Responsive:** Fast, fluid dark-mode UI optimized for all devices and screen sizes.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Modern CSS3 (CSS Variables, Flexbox/Grid), Vanilla JavaScript (ES6+)
- **Hosting:** GitHub Pages
- **Typography:** Space Grotesk, Inter, JetBrains Mono
